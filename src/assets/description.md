# src/assets

Static assets bundled with the app: the JetBrains Mono webfont family used as the primary typeface, plus a few image files. Fonts are loaded via `@font-face` declarations in `src/index.css`; the images are not currently referenced from the `src/` source tree.

## Files

### JetBrainsMono-Regular.woff2
- **Type / size hint:** WOFF2 webfont (regular weight, upright)
- **Referenced by:** `src/index.css` (`@font-face` declaration)

### JetBrainsMono-Italic.woff2
- **Type / size hint:** WOFF2 webfont (regular weight, italic)
- **Referenced by:** `src/index.css` (`@font-face` declaration)

### JetBrainsMono-Bold.woff2
- **Type / size hint:** WOFF2 webfont (bold weight, upright)
- **Referenced by:** `src/index.css` (`@font-face` declaration)

### JetBrainsMono-BoldItalic.woff2
- **Type / size hint:** WOFF2 webfont (bold weight, italic)
- **Referenced by:** `src/index.css` (`@font-face` declaration)

### hero.png
- **Type / size hint:** PNG image
- **Referenced by:** unused (no references found in `src/`)

### react.svg
- **Type / size hint:** SVG icon (default Vite + React template asset)
- **Referenced by:** unused (no references found in `src/`)
